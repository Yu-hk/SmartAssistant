# 管理员访问记录

管理后台 `/admin/visits` 提供访客列表、模块统计和浏览明细，支持日期（北京时间）、身份、模块、用户名及访客标识筛选，按 20 条分页。点击访客可查看该浏览会话的轨迹。

- 采集从部署后开始；浏览器页面上报成功才计数，不从历史接口日志推断页面访问。
- 访客 ID 保存在 sessionStorage，表示浏览会话；登录身份只取网关验证后的用户 ID。访客数按浏览会话与登录身份分组，不等于自然人数。
- 页面导航记录 PAGE_VIEW，侧边栏服务入口点击记录 ENTRY_OPEN；连续点击同一入口 2 秒内合并。同一 eventId 重传不重复计数。
- 不记录提问、表单内容、查询串、完整 URL、IP 或原始 User-Agent；只提取浏览器和设备类型。浏览器关闭采集、拦截请求或网络失败会导致少计。
- 模块元数据位于 consumer 的 `visit-modules.properties`，前端从 `/api/public/visit-modules` 获取。公开采集接口仅允许公开模块；客户和管理模块经 `/api/visits` 的登录验证；查询接口 `/api/admin/visits` 仅管理员可用。
- 数据存储在独立的 `site_visit_event` 表，由 consumer 启动时执行幂等建表。迁移 SQL 为 `20260923_add_site_visits.sql`。默认保留 90 天，`visits.retention-days` 可调整为 1–365 天，每日自动清理过期访问记录。

升级验证应覆盖匿名登录页、登录后的工作台/服务入口、管理页切换、普通用户访问管理接口返回 403、重复 eventId、筛选及分页。无需下单、付款或退款。
