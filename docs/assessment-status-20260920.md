## 本轮发现：并行等待异常导致整批重放

`AgentToolExecutor` 原先将并行批次的等待异常统一回退为串行执行。两个已开始的模拟工具，在调用线程中断后总调用次数为四次。另有超时响应丢失工具 ID、异常 future 重跑成功兄弟调用、已中断请求仍能执行单工具的问题。

本轮先使用无网络、无真实业务的回调复现：新增五项并行测试中四项失败。修复采取最小边界变更：

- 使用可取消 Future 和批次截止时间；按调用顺序保留已完成结果。
- 中断保留线程标记并传播 CancellationException，不再整批串行回退；阻止已中断请求和未开始的排队回调继续执行。
- 超时/结果不明保留调用 ID、工具名，输出 UNCONFIRMED 和 retryable=false，不暴露异常正文。
- ReAct 在入口、循环及模型返回后检查中断；已消费 Token 先记账，再停止工具执行。显式取消不包装成模型故障。

这不表示远程写操作已撤销：忽略中断的外部调用可能已提交，必须核验原操作；本补丁不解决分布式 exactly-once。已有单工具的业务错误重试策略不在本轮重写。主循环的墙钟超时仍是轮次边界检查，不是供应商 HTTP 强制超时；压缩基线使用模拟压缩器，不代表真实摘要质量验证。
