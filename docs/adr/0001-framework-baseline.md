# ADR 0001：保留当前框架基线，升级与回滚以证据为门槛

日期：2026-09-17。状态：接受（当前治理决定，不是事后编造的升级动机）。

## 背景

报告使用 PR #50 的代码基准，正确指出技术手册滞后，但报告本身也把 Nacos 服务端
写成 2.3。当前依赖和镜像的准确声明由 [项目上下文](../../ai-project-context.md) 自动生成。
Boot 4.1.0、Spring AI 2.0.1 已存在于本次调整前的根 POM；本次不升级或降级框架。
仅凭版本“激进”不能证明不兼容；也不能凭编译通过就宣称所有适配器兼容。
原升级动机及完整版本对比证据未核实，不能把历史记忆当作 ADR 的事实。

## 决定

- 保持当前可运行版本，版本事实跟随 POM / package.json / Compose，并以 CI 防漂移。
- 框架升级必须独立 PR，附依赖树、对应模型/工具协议/存储适配器回归、产物哈希及回滚点。
- 不为文档治理修改生产依赖或数据库结构，不进行未经测试的整栈降级。
- 只对实际启用的适配器给出兼容性结论；Milvus 等可选组件保持“未认证”，不能由 SDK 存在推断线上启用。

## 验证矩阵（测试范围，不是厂商认证）

| 边界 | 当前证据入口 | 仍未证明 |
| --- | --- | --- |
| Boot / Java / 模块依赖 | compile-all、Enforcer、模块扫描边界门禁 | 所有部署拓扑 |
| Spring AI / ToolCallback / 提示词 | common Agent 与工具 schema 测试、商品证据门禁 | 所有模型厂商协议 |
| langgraph4j | Router graph/checkpoint/取消回归 | 多副本长时间故障恢复 |
| PG / pgvector | 本轮严格真实 PG 契约门禁 | Flyway 全历史迁移、真实模型召回率 |
| Redis | PR #53 真实 Lua 会话门禁 | 集群分区与所有租约子系统 |
| RabbitMQ 4.1 | 本轮真实 Quorum 优先级/手工 ACK 测试 | 集群选主与全写操作 exactly-once |
| Milvus / 外部 MCP | 需专项适配器验证 | 本轮不做生产兼容承诺 |

## 回滚

按 [发布回滚检查单](../deployment-rollback-runbook.md) 保存上一套应用产物、配置引用和校验值。
数据库只允许先扩展再收缩；发生不兼容迁移时禁止简单替换旧 JAR。
不在本轮虚构“可一键退回 Spring Boot 3.x”的能力。
