## 线上验收结果

Edge 无头浏览器 + 合成麦克风，使用新建普通用户；真实 HTTPS、JWT、ASR、客服任务和 TTS，无模拟 API。最终 17 项检查全部通过：

1. 未登录并伪造身份头请求语音接口，返回 401。
2. 普通用户注册成功。
3. 页面登录成功。
4. TTS 能力已启用。
5. 录音经真实 ASR 返回文字。
6. 转写后尚未发送客服请求或合成语音，必须确认。
7. 确认发送后真实 TTS 返回 MP3，最后一次为 43,027 字节、真实计费字符数 23。
8. 音频响应包含 `private, no-store` 和 `nosniff`。
9. 浏览器实际播放、暂停和继续成功。
10. 再次录音停止播报，录音期间不提供朗读入口。
11. 当前会话重播使用内存音频，不再次调用 TTS。
12. 第二个普通用户不能合成第一个用户的请求，返回 404。
13. 非法请求 ID 返回 400。
14. 不存在的完整结果返回 404。
15. 文字提问完成后不自动触发 TTS。
16. 390px 手机宽度无横向溢出。
17. 无页面脚本错误。

合成麦克风循环样本识别为“请查询我的订单物流。请查。”，验收在确认发送前去除尾部重复并改为“请查询我当前账号的订单列表。”；新账号无订单，文字回复“当前没有查询到你的订单。”与场景一致，再自动合成播放。后续商品文字提问用于确认不会自动播报，未创建订单或执行支付。

## 本轮发现和处理

- 初版只允许 `COMPLETED` 工作流，错误地拒绝正常 `CLARIFICATION` 澄清。已补充状态区分及回归，任务调度本身仍须完成，`FAILED`、`CANCELLED`、`DEGRADED`、`AWAITING_APPROVAL` 不允许合成。
- 浏览器调试协议对音频 `response.body()` 偶发返回 0 字节，不能据此认定应用收到空正文。通过 Consumer 实际字节数、原生 Fetch 创建的 Blob 字节数和浏览器播放状态交叉验证。最终验收没有包装或替换 Fetch；只观察播放器实例，实际 Blob 长度与 HTTP Content-Length 相同。
- 网关和 Nginx 均添加 `nosniff`，响应可能为 `nosniff, nosniff`；验收按多值语义判断，没有删除安全头。
