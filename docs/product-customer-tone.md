# 商品客服表达调整（第一版）

## 范围与设计

- 商品 Agent 改为自然、礼貌的客服表达：先回答当前问题，简单询价/库存查询优先使用一至三句短段落，减少报告式标题和无关规格、销量、评分。
- 保留工具调用、事实约束、型号消歧和下单确认边界。只修改商品服务，不新增模型润色请求或服务，不改变 Router 的协调职责。
- JDBC 与演示商品后端的价格工具不再硬编码免息分期；库存工具不再硬编码发货时效、催单或补货承诺。缺失/未知库存与明确缺货分开处理。
- 用户明确询问分期、优惠、发货等政策时，由商品详情 Skill 查询知识库；缺少依据时表达“尚未确认”，而不是“不支持”。

## 本地验证

2026-09-17 使用 Java 21、Maven 离线仓库完成 product 及依赖模块打包，选定回归集共 73 项测试通过，无失败。覆盖客服提示词约束、Skill 配置、JDBC/演示后端、工具、流式商品服务、领域校验和推荐安全。

新增回归覆盖：价格不附加融资承诺，库存不附加配送承诺，空值/未知库存不误报缺货。相应测试加入 GitHub product-evidence-gate。提示词测试是资源约束测试，不代表模型对每次表达都能完全遵从。
