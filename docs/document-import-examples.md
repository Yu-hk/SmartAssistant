## 操作流程

1. 下载示例后用“导入本地文档”重新选择，或直接点击“载入示例”。
2. 预览正文，编辑验证问题。
3. 点击“将资料和问题填入输入框”。如果已有草稿，先勾选确认替换。
4. 检查上方输入框，用户自行点击发送。导入本身不自动发送。

浏览器只读取 UTF-8 TXT / Markdown，最多20 KB、6000个字符；问题最多300个字符。不支持 PDF、Word、OCR 或云端文件存储。正文按 `【资料】…【问题】` 格式随本轮消息提交，调用已部署的限定资料问答路径；不依赖跨轮文档记忆。

关闭/暂停会话、生成中及读取中禁用操作，异步读取结果在失效后丢弃。空文件、非法UTF-8、二进制控制字符、超限内容及保留分隔标记都会被拒绝。正文只以纯文本预览，不渲染文件内HTML。

## 验证与发布范围

`npm run test:scenarios` 覆盖10项首页/文档读取测试，检查实际样例文件、资料与问题组装、错误边界、下载链接和禁用状态。生产构建会将3份样例复制到 `dist/examples/documents/`。未将SSR检查描述为真实浏览器文件选择器验收。

本地前端回归共28项通过（10项首页/文档、15项登录/用量/会话洞察、3项步骤），生产构建通过。部署时必须同时复制 `dist/examples/`；只更新index和assets会遗漏下载文件。
