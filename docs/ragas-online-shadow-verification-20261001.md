# 线上商品四维影子评测与诊断修正（2026-10-01）

## 结论与边界

8 个冻结合成只读商品问题、3 次相同输入重复评分，96 项均成功返回；已真实调用 Ragas 0.4.3、DeepSeek 评判模型和生产 BGE 向量服务，不是注入评分器生成的质量结果。目录单价、三个数量合计及未知重量说明与冻结金标一致；低分与波动主要集中在未知答案、数量计算上下文、多商品相关性。**不能据此证明所有低分均为误判，也没有依据开启自动重检索或替换生产权重。**

本轮只修正离线影子诊断与复放工具：保留原始分数，在缺项/不稳定优先级不变的前提下保留证据类型线索；完整多商品低相关性单独复核。没有调整指标公式、阈值、线上业务 JAR、生产检索参数或自动重试开关。

## 实验设计与真实输入

- `data/ragas_online_shadow_questions.json` 在采集前冻结人工参考答案、字段 ID 和目录价格。前四题沿用原金标，增加未知单字段、反向商品顺序、单商品数量、多商品数量四个诊断探针；这不是独立泛化留出集，也不是检索策略 A/B 实验。
- 商品服务执行 8 次 `RESOLVE_READ_ONLY_PRODUCT`；参考答案不发送给业务服务。只读数据库核对耳机 1999 元、电脑 8999 元及耳机重量缺失，未读取真实用户会话。
- 采集绑定回复指纹、按序字段证据与摘要、请求槽位覆盖；所有 8 题覆盖完整。`UNKNOWN` 表示明确知道资料缺失，不表示拿到了具体重量。ID Recall/Precision/AP 均为 1，不与模型四维评分混报。
- 证据来源 `catalog_field_evidence`，目录解析阶段没有调用生成模型；不包含完整 Router、实际入模 Prompt、知识库 BM25/稠密检索候选排名。因此本实验不能证明完整 RAG 检索质量或全流程质量。
- 用户明确授权把上述合成问题、参考答案、目录回复及字段证据发送至 DeepSeek 评判服务，三轮付费调用；没有发送真实用户文本、收货信息或余额数据。

### 原因分析：已观察事实与未证明推断

1. 混合未知题相关性三轮为 `0.7472550316368346 / 0 / 0.7472550316368346`；未知单字段三轮均为 0。当前安装的 Ragas 0.4.3 `AnswerRelevancy` 实现从回复生成三个问题，再计算与原问题的向量相似度；如果生成项全部判为 noncommittal，结果会乘为 0。提示中将“我不知道”列为该类别。**这为诚实未知回答的低分提供可能解释；本轮未保存逐项 noncommittal 标记，不能声称已经证明每次零分都由该机制导致。**
2. 数量合计 12997 / 5997 / 19997 元与独立金标相符，但回复还有“未包含未核实的运费或优惠”等限定。评分上下文只有目录单价及数量，没有完整计算说明、政策或入模 Prompt。低忠实度可能来自衍生算术/限定语不被当前证据完整支持；本轮未记录逐命题判决，不能把低分强行改成 1，也不补造运费政策。
3. 两个价格事实齐全、忠实度为 1 时，整体相关性仍约 0.77。逆向生成的问题可能只覆盖一个商品，整体余弦评分不等于逐商品事实覆盖。当前 0.8 是调查阈值，尚未按真实问题分布校准；低于阈值不能直接证明召回有缺陷。新的逐商品复核分类只改变调查方向，不宣称已得到分商品模型分数。
4. 8 题均是固定目录正例/诚实未知，没有本轮独立负例对照；本轮高召回/精度不证明评判器对错误答案的区分能力，也不代表全量商品、复杂实体或真实用户问题。

## 依据结果实施的修正

`scripts/ragas_feedback.py` 增加正交 `review_flags`：明确未知字段、确定性合计上下文、多商品回答。评分不可用、少于三轮、极差超过 0.2 的优先行动不变，但不会因此丢失证据类型线索。槽位完整且稳定低相关性的多商品案例进入 `MULTI_PRODUCT_RELEVANCY_REVIEW`；未知、生成忠实度、缺失字段和身份未确定仍各走原专门复核。

新增 `--replay-report` 仅重新分类同一完整报告。验证数据/案例/原始逐轮指标/错误类型/耗时/汇总一致，拒绝漂移或非法值，拒绝覆盖旧证据。复放不导入模型库、不读取模型密钥；在服务器 Python 3.12 隔离容器以 `--network none` 实际运行。服务器原生 Python 3.6 不支持 `asyncio.run`，首次原生执行未产生输出，随后使用固定镜像成功复放。原始报告和采集脚本保留。

服务器新旧报告逐题核对：24 组评分轮次、96 项分数及全部汇总/耗时/错误/输入摘要未变；仅两道稳定多商品价格题的行动由一般回答范围复核转为逐商品复核。未知混合题继续要求校准，未知线索仍可见。`new_model_calls=0`、`ragas_scores_adjusted=false`、`retries_executed=0`。

```sh
python scripts/ragas_feedback.py --dataset dataset.json --replay-report baseline-3rounds.json --output new-diagnostic-replay.json
python -m unittest discover -s scripts -p test_ragas_shadow_replay.py -v
```

本地新增 13 项契约；全量 Python 281 项，280 项通过，1 项 POSIX 权限检查在 Windows 跳过。CI 新增复放契约步骤。契约测试使用固定注入值，只证明校验和分类，不冒充真实模型效果。

## 生产隔离与页面回归

Playwright 另创建专用合成 QA 账号，Chrome、Edge 同账号各两次只读提问，四次刷新和跨浏览器恢复通过，无 pageerror。12997 元合计正常；未知重量明确未核实，电脑价 8999 元。已查看两浏览器未知字段截图，主对话与输入布局可读。账号与四条对话保留，没有下单、扣款、物流或会话删除。这是现有业务页面回归，**影子诊断没有页面入口**，不代表在线闭环已上线。两浏览器截图右侧用量/工具统计显示不一致，本轮未验收或修正该统计展示，须另行核实，不能把零展示当作没有实际调用。
