# ORD-STATUS-v1 订单状态

订单状态依次包含待付款、待发货、已发货、已签收、已取消和退款中。用户提供订单号后，应返回当前状态及最近更新时间。演示订单 ORD-1001 为待付款，ORD-1002 为待发货，ORD-1003 为已发货，ORD-1004 为已签收，ORD-1005 为退款中。

# ORD-TRACKING-v1 物流跟踪

已发货订单可通过订单号或快递单号查询。结果应包含承运商、快递单号、当前节点和按时间排序的物流轨迹；待发货订单没有物流轨迹时应明确说明尚未交付承运商。

# ORD-SHIPPING-TIME-v1 配送时效

普通订单付款后通常在 24 小时内发货，一线城市预计 1 至 3 天送达，其他地区预计 2 至 5 天。周六日正常配送，法定节假日及极端天气可能顺延，具体以承运商轨迹为准。

# ORD-REFUND-POLICY-v2 退款规则

未发货订单取消后原路退款，一般 1 至 3 个工作日到账；已发货订单需完成拦截或退货验收，一般在验收后 3 至 7 个工作日到账。退款金额以实际支付金额为上限，已使用且不可退回的优惠权益需要按活动规则扣除。

# ORD-CANCEL-REFUND-v1 取消订单退款渠道

取消订单后资金退回原支付渠道。微信、支付宝通常 1 至 3 个工作日到账，银行卡通常 3 至 7 个工作日到账。高风险取消操作必须经过用户确认并记录审批状态。

# ORD-AUDIT-PROCESS-v1 订单审核

大额、异常地址、频繁下单或风控命中的订单可能进入人工审核。正常审核目标时效为 2 小时，最长不超过 24 小时；审核期间不得重复扣款或重复创建订单。

# ORD-ADDRESS-CHANGE-v1 修改配送地址

待付款和待发货订单可以申请修改地址；已发货订单只能尝试联系承运商改址，无法保证成功。涉及跨区域运费变化时需重新确认费用。

# ORD-COUPON-REFUND-v1 优惠券订单退款

优惠券订单按实际支付金额退款。整单退款时，仍在有效期且规则允许的优惠券可以退回账户；部分退款、已过期优惠券或一次性活动券通常不退回。

# ORD-HISTORY-v1 历史订单

用户可以按时间、状态或商品名称查询历史订单。查询结果应限制在当前登录用户范围内，默认按创建时间倒序展示，不得泄露其他用户订单。

# ORD-POINTS-DEDUCTION-v1 积分抵扣

结算页展示可用积分及抵扣上限。积分不能超过订单可抵扣金额，退款时按原订单规则退还可退积分；具体比例以结算页显示为准。

# PRD-iPhone15ProMax-PRICE-v1 iPhone 15 Pro Max 价格

iPhone 15 Pro Max 的演示参考价格为 9999 元起。实际成交价受容量、活动和优惠券影响，回答时应同时提示以实时商品数据为准。

# PRD-iPhone15ProMax-REVIEW-v1 iPhone 15 Pro Max 评测

该机型优势包括性能、影像和生态协同，适合重度拍摄与高性能需求；价格和机身重量是主要取舍。性价比判断应结合预算、容量和换机周期，不应只给单一结论。

# PRD-iPhone15ProMax-SPEC-v1 iPhone 15 Pro Max 规格

演示规格包含 USB-C 接口、无线充电、5G、全天候显示和多摄像头系统。涉及精确功率、频段或兼容性时应查询最新商品参数后回答。

# PRD-WatchS3-STOCK-v1 南屿 Watch S3 库存

南屿 Watch S3 是评测集中的演示商品。库存状态以实时商品服务为准；无库存时应说明补货未知，并推荐相近价位的可用型号，不得虚构到货日期。

# PRD-Watch-COMPARE-v1 手表型号对比

手表选型应比较价格、续航、健康传感器、屏幕和手机兼容性。性价比最高取决于用户需求：基础运动记录优先入门款，健康监测和独立通信需求优先高配款。

# PRD-AirPods-BUNDLE-v1 AirPods 组合购买

AirPods 与 iPhone 可以一起购买。组合优惠必须以商品服务返回的实时活动为准；没有活动时应分别展示价格，不得承诺不存在的捆绑折扣。

# PRD-AirPods-REVIEW-v1 AirPods 音质评价

AirPods Pro（第二代）的特点包括主动降噪、自适应音频和 Apple 生态协同。音质偏好具有主观性，回答应区分通勤降噪、通话、音乐风格和佩戴舒适度。

# PRD-MacBook-COMPARE-v1 MacBook Pro 与 Air 对比

MacBook Air 更轻、更安静，适合办公、学习和轻量开发；MacBook Pro 具备更强持续性能、更多接口和更好的屏幕，适合编译、视频和专业负载。推荐前应确认预算、内存和工作负载。

# PRD-COUPON-POLICY-v1 商品优惠券

优惠券分为满减、折扣和现金券。是否可用取决于用户、商品范围、门槛、有效期和是否已使用；最终可用性以结算校验结果为准。

# PRD-REORDER-v1 再次购买

历史订单中的在售商品可以再次加入购物车。商品下架、规格变化或库存不足时，应推荐可替代商品并重新确认价格，不能复用旧订单价格直接下单。

# PRD-PRICE-PROTECTION-v1 价格保护

符合活动规则且仍在价保期内的订单可以申请退差价。优惠券、限时秒杀、赠品和跨平台价格通常不计入价保；提交后需校验订单、时间和活动类型。

# PRD-iPad-EDUCATION-v1 学生平板建议

iPad Air M2 适合笔记、阅读、网课和轻量创作。学生购买前应比较容量、键盘和手写笔成本，并确认学校所需软件是否支持移动端。

# POLICY-RETURN-v2 退货政策

商品完好且不影响二次销售时，可在签收后 7 天内申请无理由退货；定制、生鲜、已激活数字商品等以商品页例外说明为准。质量问题运费由商家承担，个人原因退货运费通常由用户承担。超过期限可提交人工审核，但不保证通过。

# POLICY-EXCHANGE-v1 换货政策

质量问题、错发或运输损坏可申请换货。审核通过后先安排寄回或上门取件，仓库验收后发出替换商品；有现货时换货通常比退款后重新购买更快，无库存时建议退款。

# POLICY-WARRANTY-v2 保修政策

保修期内的非人为质量故障按品牌政策免费维修。进液、跌落、私拆等人为损坏及耗材老化通常不在免费范围；保外维修需检测后报价并经用户确认，不得在检测前承诺具体费用。
