# JD-SELF-AFTERSALES-v1 退换货时限

本知识条目根据京东帮助中心公布的自营商品售后政策整理。符合政策条件时，自签收商品次日起七日内可申请退货、十五日内可申请换货；自营小时购等特殊商品可能不支持换货，应以订单和商品页标识为准。

# 质量问题与物流异常

功能性故障或质量问题经厂家指定服务中心检测确认，或经京东售后确认后，可按政策申请退换货。运输造成的损坏、缺件或与网页描述不符，应及时反馈；页面当前要求物流损在收货后二十四小时内反馈，审核时可能需要照片或承运人员证明。

# 无理由退货条件

个人原因退货要求商品完好、附件齐全，并排除页面明示不支持无理由退货的商品。定制、鲜活易腐、已下载或拆封的数字商品、报刊，以及激活或试用后价值贬损较大的商品等通常不适用。

# 不予办理的常见情形

非京东出售或序列号不符、超过保修期、未经授权维修、误用碰撞或进液、三包凭证与商品不符或被涂改等情形，可能不予办理退换货。

# 优惠与赠品处理

退货时，评价或晒单获得的京豆及相应优惠可能被扣回；已使用的京豆可能从退款金额中扣除。主商品退货时赠品需要一并退回，赠品缺失可能导致无法全额退款。

# 使用边界

本摘要只描述京东自营政策，不适用于第三方商家、香港京东 MALL 或其他独立规则场景。售后处理前应检查具体订单、商品页和帮助中心最新规则。
