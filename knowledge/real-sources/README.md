## 摄取建议

- 摄取租户使用 `public`，保留文件中的 `sourceUrl` 和 `retrievedAt`。
- 法规与商家政策分开建立类别过滤，回答时优先法规，再补充适用的商家承诺。
- 商家政策到达 `expireAt` 前应重新核验；未核验时降级为“请以官方页面为准”。
- 回答中区分法定权利、平台规则和厂商承诺，避免把某一品牌政策泛化到所有商品。
- 不根据摘要自动批准退款或保修，最终判断仍需订单、商品状态、凭证和官方检测结果。
