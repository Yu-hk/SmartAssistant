# LOGISTICS-REGULATION-v1 快递服务基础义务

本知识条目根据司法部国家行政法规库中的《快递暂行条例》整理。经营快递业务的企业应加强服务质量管理，为用户提供迅速、准确、安全、方便的快递服务。

# 查询和投诉

快递企业应实行快件寄递全程信息化管理，公布联系方式，保持与用户联络畅通，并提供业务咨询和快件查询服务。用户对服务质量不满意时，可以向企业投诉；企业应自接到投诉之日起七日内处理并告知用户。

# 收寄安全

快递企业收寄快件时应依法验视内件并作出标识。寄件人拒绝验视的，企业不得收寄。发现禁止寄递或疑似禁止寄递物品时，应依法拒绝收寄或停止分拣、运输和投递，并按规定报告、配合处理。

# 用户信息保护

快递企业应建立运单及电子数据管理制度，妥善保管用户信息并定期销毁运单。企业及从业人员不得出售、泄露或非法提供在服务过程中知悉的用户信息；发生或可能发生泄露时，应立即采取补救措施并向所在地邮政管理部门报告。

# 停运与未投递快件

企业停止经营时应提前公告、告知邮政管理部门并妥善处理尚未投递的快件。因不可抗力或其他特殊原因暂停服务时，应报告并公告原因和期限，同时妥善处理未投递快件。

# 使用边界

本摘要适合用于物流查询、投诉处理、隐私保护和异常停运问答，不包含具体承运商的价格、赔偿限额或时效承诺。具体业务应同时查询运单契约和承运商最新规则；发生冲突时以来源页面及现行法规为准。
