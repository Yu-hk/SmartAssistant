# XIAOMI-AFTERSALES-v1 三包时限

本知识条目根据小米官方服务保障政策整理。在三包有效期内，用户办理修理、换货或退货应提供发票和三包凭证。

手机主机自收货日起七日内出现政策列明的性能故障，经小米售后服务中心检测确认后，可以选择免费退货、换货或维修。第八日至第十五日出现同类性能故障，可以选择免费换货或维修。自收货日起十二个月内出现同类性能故障，可以免费维修。

# 附件保修

页面列明电池保修六个月、充电器保修一年、外接有线耳机保修三个月。附件出现政策列明的性能故障，经检测确认后可更换同品牌、型号和规格的附件。

# 取件和邮资

页面说明办理退货、换货和保修服务时可安排免费上门取货；无法安排上门取货的地区提供邮资报销，页面当前列出的最高限额为每单十五元。实际申请前应再次核验页面。

# 常见排除情形

未经授权维修、误用、碰撞、进液、改动、错误使用非原配件或安装软件系统造成的问题，以及标识被撕毁或涂改、超过三包期、不可抗力、人为原因等，可能不属于三包范围。

# 使用边界

是否属于性能故障和保修范围须由官方售后检测。本摘要不替代检测结论；商家政策可能更新，处理工单时应回查来源页面。
