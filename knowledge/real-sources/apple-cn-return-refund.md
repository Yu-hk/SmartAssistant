# APPLE-RETURN-REFUND-v1 适用范围

本知识条目基于 Apple 中国大陆在线商店的退货与退款帮助页面，仅适用于通过中国大陆 Apple Store 在线商店或电话中心购买的商品。其他授权渠道购买的商品应咨询对应销售方。

# 标准退货政策

符合条件的商品可以在交付之日起十四个自然日内发起退货。商品应保持未损坏状态，并连同原始零件、配件、发票和包装退回。在线订单可通过订单详情发起退货；零售店取货的订单可以退回原取货门店。

退货前应关闭与防丢失或防盗有关的安全功能，并自行擦除、备份个人数据。未关闭相关安全功能时，Apple 可能拒绝退换货。

# 不可退商品与特殊商品

下载的电子软件、软件升级计划、Apple Store 礼品卡和 Apple 开发者联盟产品不可退货。带有可见软件许可封印的软件在拆封后通常不可退。定制第三方产品及 Apple Watch 特殊系列可能适用单独条件，应以页面对应章节为准。

# 退款

退款原则上退回原支付方式，具体到账时间取决于付款渠道和金融机构处理。Apple 收到并检验退回商品符合条件后开始处理退款。加急发货费用通常不在退款范围内。

# 价格调整

Apple 品牌产品在消费者收到后的十四个日历日内发生非限时降价时，页面提供了联系 Apple 申请差价退款或抵扣的路径；消费者还需在价格变更后的十四个日历日内提出。限时促销不适用该政策。

# 使用边界

商家政策可能调整，回答前应核验来源页面。除商家政策外，消费者仍享有中国大陆三包规定及其他法律赋予的权利。
