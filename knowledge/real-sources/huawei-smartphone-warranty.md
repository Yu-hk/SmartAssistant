# HUAWEI-WARRANTY-v1 适用范围

本知识条目根据华为消费者业务中国大陆官方保修政策整理，适用于中国大陆官方渠道销售的华为手机及随机配件。华为授权第三方平台销售的产品，保内维修由华为提供，退换货通常需要联系销售方。

# 保修期限

页面列明手机主机保修一年；随包装的数据线和充电头保修一年；有线耳机保修九十天。不同产品和配件可能存在差异，应结合具体型号和购买凭证核验。

# 保修凭证

支持的凭证包括纸质或电子发票、电子三包凭证和签收记录。无法提供发票、保修卡或其他有效销售证据时，页面说明可按出厂日期向后顺延九十日计算保修起始日期。

# 退换修期限

对于主机非人为性能故障，线下购买自售出之日起七日内、线上购买自签收次日起七日内，可按政策选择退货、换货或免费维修；第八日至第十五日可选择换货或免费维修。具体处理需经授权服务中心检测确认。

# 维修与数据

送修前应备份个人数据。产品需经授权服务中心检测后确定维修方案。保外或不符合保修条件的维修可能收费，服务中心应提供维修报告。

# 使用边界

本摘要不用于判断某一台设备是否属于人为损坏，也不替代现场检测。政策只覆盖中国大陆适用范围；发生冲突时以华为最新页面和现行法律法规为准。
