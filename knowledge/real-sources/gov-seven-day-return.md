# POLICY-RETURN-LAW-v1 适用规则

本知识条目根据国家市场监督管理总局公布的《网络购买商品七日无理由退货暂行办法》整理。消费者为生活消费需要通过网络购买商品，自收到商品之日起七日内行使无理由退货权，七日期间从签收次日起计算。

# 不适用范围

依法不适用七日无理由退货的商品包括消费者定作商品、鲜活易腐商品、在线下载或已拆封的数字化商品，以及已交付的报纸和期刊。

对拆封后影响人身安全或品质、激活或试用后价值贬损较大、销售时已明示的临期或瑕疵商品，经营者只有在购买必经流程中作出显著提示并取得消费者单次确认后，才可以不适用无理由退货。

# 商品完好与退回内容

商品保持原有品质和功能，商品本身、配件及商标标识齐全，可以视为完好。为了查验而打开包装或进行合理调试，不当然影响商品完好。退货时应将商品、配件和赠品一并退回；赠品包括实物、积分、代金券和优惠券等。

# 退款与运费

商品完好时，销售者应在收到退回商品之日起七日内返还已支付价款。退款方式原则上比照原支付方式；积分、代金券和优惠券原则上按相应形式返还，但双方已有明确约定的可按约定处理。

退货价款以消费者实际支出为准。套装或满减活动中的部分商品退货导致优惠条件不再满足时，可根据购买时各商品价格重新结算。无理由退货产生的运费原则上由消费者承担，经营者另有更有利约定的除外。

# 使用边界

质量不合格商品的退货不只适用“七日无理由”规则，还应按消费者权益保护法及其他质量责任规定处理。本摘要用于检索和客服辅助，不替代监管部门公布的原文；发生冲突时以来源页面和现行法律法规为准。
